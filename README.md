A make.fun entry for [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea): one funny line of text, at most 200 characters, judged head-to-head by an AI judge.

## The line

> I asked AI to write my apology; it said sorry so well my girlfriend forgave the robot, not me.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It is deterministic and writes exactly one line to `/output/entry.txt`.
